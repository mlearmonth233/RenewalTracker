How alerts work

  • Each item has reminder stages, for example 30,7,1 days before. One alert is raised per stage, plus on the day and when overdue.
  • The server checks automatically every few hours. You can also trigger a check from the dashboard.
  • New alerts show in-app, are pushed to any device where you allowed notifications, and are e-mailed if the server has SMTP configured.
  • Passports default to reminders at 270, 180 and 90 days because many countries require six months of remaining validity.
  • Export everything to your calendar with the .ics button on the Items page.
